## 13:15 - Vercel Hobby hosting requirement

- **Decision:** User specified Vercel free-plan hosting. Replace deployed filesystem storage with Neon PostgreSQL over the serverless driver, serve the static Vite build from Vercel, and route API requests through one Node function. Keep SQLite only as a zero-setup local development option. The private single-user deployment uses a password and signed HTTP-only session cookie; cloud configuration fails closed when missing.
- **Alternatives:** SQLite on the function filesystem cannot provide persistent deployed storage. A dedicated always-on server conflicts with the hosting requirement. Store the small personal workspace as a versioned JSONB aggregate under a PostgreSQL row lock, preserving atomic commands and idempotency without maintaining two divergent relational persistence implementations.

## 13:24 - User-provided database URI

- **Alternatives:** MongoDB is viable, but PostgreSQL row locks and transactions fit concurrent check-ins and reward accounting directly. Supporting both databases now would duplicate deployment and testing paths without a requested benefit.
